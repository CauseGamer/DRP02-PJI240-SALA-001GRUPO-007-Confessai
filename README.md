## 💡 Sobre o Projeto

O **ConfessaiApp** é um aplicativo de página única (SPA) desenvolvido para ajudar os usuários a monitorar e registrar seus estados de humor, atividades e pensamentos diários. Nosso objetivo é fornecer uma ferramenta simples e intuitiva para promover a autoconsciência e o bem-estar emocional, utilizando a estrutura robusta e em tempo real do Firebase.

Este projeto faz parte da disciplina **DRP02-PJI240-SALA-001GRUPO-007**.

### Funcionalidades Principais

* **Autenticação Segura:** Login via Google (Firebase Auth).
* **Registro Diário:** Páginas para registrar humor, atividades e notas.
* **Histórico:** Visualização de registros anteriores.
* **Bem-Estar:** Seção dedicada a dicas e monitoramento de saúde mental.
* **Interface Intuitiva:** Design responsivo e moderno com **Tailwind CSS**.

## 🛠️ Tecnologias Utilizadas

O projeto foi construído com as seguintes tecnologias:

* **Frontend:**
    * **React:** Biblioteca JavaScript para construção da interface de usuário.
    * **Tailwind CSS:** Framework CSS *utility-first* para um *design* rápido e responsivo.
    * **Vite:** *Tooling* moderno para desenvolvimento rápido (bundler).
* **Backend & Serviços:**
    * **Firebase Authentication:** Gerenciamento de usuários e login com Google.
    * **Firestore:** Banco de dados NoSQL para armazenar registros de humor e dados do usuário.
    * **Firebase Hosting:** Hospedagem e deploy do aplicativo web.
